Echte Originalfotos statt WhatsApp/Instagram bringen trotzdem mehr als jede Hochrechnung.
- 2026-10-19 · Webdesign · Malik wollte das Showreel in 4K, Quelle war aber ein WhatsApp-Video mit 1024×576 (WhatsApp verkleinert) → Hochrechnen erfindet keine Details. - 2026-10-12 · Setup und Technik · Unter Windows brach der Neubau der Website ab, weil das Video gerade im Browser lief (Datei gesperrt) → Build kopiert jetzt nur Geändertes und überspringt gesperrte Dateien statt abzubrechen.

- 2026-10-18 · Webdesign · Löschflächen fürs Freistellen am fertigen Bild gemessen, das Skript rechnete sie aber vor dem Verkleinern → Skript so umgestellt, dass Koordinaten im fertigen Bild (max. 1200 px) gelten.
- 2026-10-19 · Bachelorarbeit · Auftrag ging von „20 → 15 Merkmale per Korrelation“ aus, im Code gab es das nie (29 Merkmale, die 15 waren nur App-Felder) → vor neuen Analysen erst prüfen, ob die Annahme im Code stimmt; Reduktion dann neu und dokumentiert gemacht (29 → 24).

Loky/joblib scheitert unter Windows an großen Modellen → Modell auf Platte speichern und mit `ProcessPoolExecutor` jeden Worker selbst laden lassen.
- 2026-10-22 · Bachelorarbeit · Optimierungslauf brach nach 5 min mit demselben loky-Fehler (`WinError 6`) ab, obwohl der Schnelltest lief: Der Test mit 12.000 Zeilen war zu klein, um das Problem auszulösen → Schnelltests mit realistischer Datengröße fahren; auf diesem Rechner joblib-Parallelität ohne loky planen (Threads oder modellinterne Parallelität).
- 2026-10-22 · Bachelorarbeit · Ein Hintergrundlauf ohne Überwachung kann unbemerkt sterben → beim Start sofort einen Wächter einrichten, der beim Prozessende Bescheid gibt, und nach den ersten Minuten das Log prüfen.
