# CLAUDE.md: Maliks Second Brain

Claude pflegt diesen Tresor eigenständig (Erlaubnis von Malik, 2026-10-11). Deutsch, Obsidian-Markdown, Links als `[[Notizname]]`.

## Ordnerstruktur
| Ordner | Inhalt | Regel |
|---|---|---|
| `00 Inbox` | Schnelles, Unsortiertes | Claude sortiert beim nächsten Besuch ein |
| `01 Projekte` | hat Ziel und Ende | eine Notiz pro Projekt, Vorlage `Projekt` |
| `02 Bereiche` | läuft dauerhaft (Finanzen, Sport, Familie, Glaube, Markt) | nur ergänzen |
| `03 Wissen` | Gelerntes | `Learnings.md`, `Prozesse und Automatisierung.md`, Themen-Notizen nach Vorlage `Wissen` |
| `04 Archiv` | Fertiges, Veraltetes | hierhin verschieben statt löschen |
| `05 Ich` | Profil, Werte, Stärken, Routine | Neues über Malik ins Profil |
| `06 Tagebuch` | Tagesnotizen `YYYY-MM-DD`, Wochenrückblicke | gehört Malik, Claude schreibt hier nicht |
| `07 Erinnerungen` | Reisen, Momente, `Bilder/` | gehört Malik |
| `08 Claude-Log` | `Log.md`: was Claude wann geändert hat | eine Zeile pro Sitzung |
| `Vorlagen` | Muster für neue Notizen | |

## Formate
- **Learning:** `- YYYY-MM-DD · [Projekt] · Was passiert ist → Was ich daraus mache`
- **Redundanter Prozess:** Tabellenzeile mit Prozess, wie oft, Aufwand, Idee zur Automatisierung, Status (offen / umgesetzt)
- **Log:** `- YYYY-MM-DD · Projekt · was im Tresor geändert wurde`

## Tabu
Kundendaten, Passwörter, Bankdaten. Texte von Malik nicht löschen oder umschreiben.
